# LEGENDS-GARAGE
Sistema web para gerenciamento de uma coleção de carros ,o sistema permitirá cadastros, listar, editar, excluir, e filtrar veículos por categoria.


Tecnologias e linguagens de programação que serão usadas: 
HTML, CSS, JAVASCRIPT, MOCKAPI, POSTMAN


CAMPOS DE COLECÃO: 

 marca
 modelo
 ano
 preço
 potencia
 categoria
